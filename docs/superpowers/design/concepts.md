# Java 阶梯视觉规范

Figma 文件：[Java 阶梯 · 深色移动端刷题](https://www.figma.com/design/lCcVtctYHLcg6qspFlGkYD)

页面以 iPhone 15 Pro 的 393 × 852 CSS 像素为主画布，采用深石墨底色与荧光青柠强调色。学习首页让“继续学习”成为一个清楚的主卡片，路线进度用两张精简阶段卡呈现。练习页收起装饰和冗余导航，优先保证题干、代码、选项与提交按钮的阅读顺序。

| 语义 | 色值 | 用途 |
| --- | --- | --- |
| 背景 | `#0C1010` | 页面底色 |
| 卡片 | `#171F20` | 主要承载面 |
| 提升层 | `#1D2828` | 代码、次级面板 |
| 正文 | `#F0F2EB` | 主文字 |
| 次级字 | `#9BA7A0` | 辅助信息 |
| 青柠 | `#C4F078` | 主要按钮、选中状态和进度 |
| 珊瑚 | `#F18B6B` | 连续学习等少量提醒 |
| 分隔线 | `#2A3634` | 卡片边界 |

字体使用 Noto Sans SC；英文标签与代码使用 Inter。正文 12–16px，标题 20–24px，触控高度至少 44px。主导航悬浮在底部安全区上方；逐题练习收起主导航，为作答操作留出空间。

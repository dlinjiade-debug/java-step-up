# Java 阶梯题库：设计说明

## 目标

制作一个独立的 Java 学习与刷题网站。主要面向使用 iPhone 15 Pro 的学习者，也能在桌面浏览器使用。用户从基础概念开始，通过逐章练习、代码分析和综合题，逐步掌握 Java；网站支持查看解析、记录错题和收藏题目，并保留学习进度。

视觉采用精致的深色学习界面：石墨黑背景、分层的深色卡片、青柠绿作为学习进度与选中状态，少量珊瑚橙点缀。用紧凑标签、课程主卡片和精简阶段卡建立阅读层级，避免重复的大块方框；确保正文和次级文字在手机 OLED 屏幕上仍有清楚对比。主要色值见 `docs/superpowers/design/concepts.md`。

首版题库目标为 300 题。先交付 30 道代表题与完整刷题流程，确认内容结构和移动端体验后，扩充到完整题量。

## 用户和学习路径

题库适合零基础到能读懂和分析常见 Java 程序的学习者。学习者可以沿推荐顺序前进，也可以直接进入已开放的章节。每道题标记知识点、学习阶段和难度。

首版的学习阶段和题量配额如下：

| 阶段 | 主要知识点 | 题量 |
| --- | --- | ---: |
| 入门 | 变量、数据类型、运算、分支、循环、数组、方法 | 60 |
| 基础 | 类与对象、封装、继承、多态、接口、字符串、异常 | 80 |
| 进阶 | 集合、泛型、IO、Lambda、Stream | 80 |
| 深入 | 线程、锁、线程池、JVM、反射 | 50 |
| 综合 | 代码分析、排错、基础算法及跨章节应用 | 30 |
| **总计** |  | **300** |

题目在各阶段内按“理解概念、阅读代码、排查问题、综合应用”逐步增加难度。首版以 Java 21 为代码题默认语言版本；题目依赖版本差异的语言特性时须明确标注。

## 题目与解析

首版支持单选、多选、代码输出和代码纠错四类题目。内容以原创为主，不直接搬运未获授权的开源仓库题干或解析。外部资料只用于确认知识点和拓展阅读，并在相关题目或资料页注明参考链接。

每道题至少包含稳定 ID、阶段、章节、知识点、题型、难度、题干、代码版本（适用时）、选项（适用时）、答案、解析和易错点。提交前不显示答案或解析；提交后展示正确答案、推导步骤、选项说明、常见误区和可继续阅读的知识点。代码样例按声明的 JDK 版本验证。

答案形式不适合客观自动判分的综合题，提供参考答案、评分要点和自我对照提示，不冒充自动评分。

## 主要页面和操作

- **首页：** 展示继续学习入口、总体进度、阶段卡片、每日建议和错题复习入口。
- **章节练习：** 可按阶段、章节、难度和题型筛选；一次聚焦一道题；选答或自我作答后查看解析，再前进或返回。
- **错题本：** 自动收集错题，可逐题重做，并允许标记已掌握。
- **收藏：** 保存值得复习的题目，可从列表直接继续作答。
- **学习进度：** 显示已做题数、正确率、各阶段进度和最近练习记录。
- **数据设置：** 导出或导入个人进度；导入时检查文件结构并预览结果后再保存。

底部导航常驻四个入口：学习、练习、错题、我的。每题答案在提交前保持隐藏。上一步、下一题、提交、选项等常用操作可以单手触达；代码块独立滚动，整页不出现横向滚动。深色背景、卡片、正文、次级文本与行动色使用统一的语义令牌，并检查文本对比。

## 手机端体验

以 iPhone 15 Pro Safari 的竖屏视口（393 × 852 CSS 像素）作为主要布局验收尺寸，桌面端做响应式适配。页面需要处理 iOS 顶部和底部安全区域、地址栏伸缩与软键盘遮挡。主要触控区域至少 44 CSS 像素；代码有语法高亮，保持可读字号和足够行距。

网站可添加到主屏幕。首次访问后缓存应用壳和已下载题目，使再次打开时能够离线练习；尚未下载的内容明确提示网络要求。离线期间产生的进度保存在本机。

## 技术和数据

网站放在工作区内独立的 `java-step-up/` 目录，使用 React、TypeScript、Vite 和 PWA。复用现有 408 应用里可迁移的题目结构、答题状态和本地进度处理思路，但不依赖或覆盖 408 应用的入口、题库和进度数据。Java 网站拥有独立存储键与独立构建配置。

首版不要求账号、云端服务或 Java 在线执行沙箱。题目和解析随站点发布；进度仅保存在浏览器本地，可以导出或导入备份。离线 PWA 缓存解决题目读取，进度写入在每次答案状态变更后进行。

题目数据需要版本号、结构校验，并检查唯一 ID、章节归属、答案与选项、代码版本、解析字段和题量配额，避免错误内容进入发布构建。

## 质量要求与验收

1. 独立开发和构建 Java 网站不会改写 408 网站的应用代码、题目或存储数据。
2. 30 道试点题覆盖五个阶段；每道题有与内容相符的答案和可读解析。题量扩充完成后按配额达到 300 题。
3. 所有单选、多选题能够显示选项并在提交后准确判分；代码输出题可以对照明确的 JDK 版本验证；纠错题有明确的错误点和修复说明。
4. 错题、收藏、答题次数和掌握状态刷新页面后保留；错题复做正确后可以更新掌握状态。
5. 手机上选项、主要按钮和导航不互相遮挡，代码块能单独横向滚动，页面无非预期横向溢出，安全区域留白正确。
6. 应用可加入 iOS 主屏幕；已缓存题目可以离线打开和提交；恢复联网后本地进度仍在。
7. 进度文件可导出，再导入后恢复记录；无效文件不会静默清空现有记录。
8. 桌面端仍可以完成选题、提交、看解析、错题复习和数据导入导出。

## 不在首版范围

账号和多设备云同步、管理后台、题目在线编辑、排行榜、付费、Java 在线编译执行，以及 Spring Boot 企业开发进阶题库不属于首版。后续可在核心学习体验稳定后单独评估。

## 主要取舍

- 独立目录和独立存储，让新站有自己的题库、部署入口和 PWA 更新，不干扰现有 408 站点。
- 离线优先和本地进度避免首版需要运营后端，同时由导入导出提供基础备份。
- 先以 30 题验证手机答题流程和解释质量，再投入完整 300 题内容制作。
- 采用原创题目并链接参考资料，方便维护和验证，也避免把公开可读误认为允许复制。
